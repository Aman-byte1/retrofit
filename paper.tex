\begin{abstract}
Low-resource and morphologically complex languages present distinct challenges for causal autoregressive language modeling. While standard transformer architectures dominate high-resource English pretraining, alternative inductive biases---such as chunk-parallel linear attention with delta update rules (Qwen3.5 Gated DeltaNet), dual-timescale hierarchical recurrent memory (HRM-Text), and continuous-time selective state spaces (Mamba)---offer promising computational and representational trade-offs. In this paper, we present the first rigorous, parameter-matched empirical comparison of four distinct language model families strictly calibrated to approximately $50$ million parameters ($\sim 50\text{M}$) trained from scratch on Amharic Wikipedia text using a reinforcement-learning-optimized subword tokenizer ($V = 3,919$). Under unified mixed-precision conditions on an NVIDIA A100 GPU, we measure convergence rate, final validation perplexity, instantaneous peak VRAM scaling, and exact token throughput. Our results show that the **Qwen3.5-style hybrid model (3:1 Gated DeltaNet to Attention with Multi-Token Prediction)** achieves the lowest validation perplexity ($\text{PPL} = 9.25$, cross-entropy loss $2.22$), while **HRM-Text** achieves competitive linguistic convergence ($\text{PPL} = 10.83$) with an extraordinary **$9.4\times$ throughput speedup** ($43,078\text{ tokens/sec}$ vs. $4,565\text{ tokens/sec}$) and **$23.8\times$ lower peak VRAM consumption** ($3.22\text{ GB}$ vs. $76.68\text{ GB}$). We release all model checkpoints, code, datasets, and benchmark metrics on the Hugging Face Hub.
\end{abstract}

\section{Introduction}

Autoregressive language models have expanded across multilingual domains, yet African languages---specifically Semitic languages utilizing non-Latin scripts such as the Ethiopic syllabary (Ge'ez script)---remain severely underserved \cite{amharic_nlp_2024}. Amharic is the second most widely spoken Semitic language in the world (after Arabic), featuring a root-and-pattern non-concatenative morphology where words are constructed from triconsonantal roots combined with complex inflectional vocalic templates and affixation \cite{bender1976language}.

Traditional dense Transformer architectures \cite{vaswani2017attention} suffer from two primary inefficiencies when deployed in resource-constrained environments:
\begin{enumerate}
    \item **Quadratic Complexity $O(L^2)$**: Standard softmax attention requires storing and computing full pairwise attention matrices over the sequence length $L$.
    \item **High Computational Redundancy**: Traditional token-by-token feed-forward computation lacks explicit hierarchical reasoning timescales.
\end{enumerate}

To overcome these constraints, modern architecture research has proposed three fundamentally distinct paradigms:
\begin{itemize}
    \item **Linear Attention with Delta Update Rules (Qwen3.5)**: Employs chunk-parallel associative memory with data-dependent update gates ($\beta$) and contractive state projections to achieve $O(L)$ linear complexity \cite{qwen2025, yang2024gated}.
    \item **Dual-Timescale Recurrent Reasoning (HRM-Text)**: Separates computation into slow high-level cognitive modules ($H$) and fast low-level processing modules ($L$) with parameterless MagicNorm and truncated backpropagation through time (TBPTT) \cite{wang2026hrm}.
    \item **Selective State Space Models (Mamba)**: Continuous-time state space models with input-dependent selection mechanisms ($\mathbf{B}, \mathbf{C}, \boldsymbol{\Delta}$) and selective discretization \cite{gu2023mamba}.
\end{itemize}

Despite theoretical claims, there is an absence of controlled, equal-parameter ($50\text{M}$) comparisons on non-Latin morphologically rich languages. In this study, we bridge this gap by designing, calibrating, pretraining, and benchmarking four parameter-equivalent architectures on a clean Amharic corpus.

\subsection{Qwen3.5 Transformer: Gated DeltaNet + Multi-Token Prediction}
The Qwen3.5-style architecture integrates chunk-parallel linear associative memory with multi-head self-attention in a $3:1$ layer ratio \cite{qwen2025}. The linear recurrence follows the contractive Delta Rule:
\begin{equation}
\mathbf{S}_t = \mathbf{S}_{t-1} (\mathbf{I} - \beta_t \mathbf{k}_t \mathbf{k}_t^T) + \beta_t \mathbf{k}_t \mathbf{v}_t^T
\end{equation}
where $\mathbf{k}_t \in \mathbb{R}^{d_k}$ is strictly $L_2$-normalized ($\|\mathbf{k}_t\|_2 = 1$) to guarantee contractive operator eigenvalues $\lambda(\mathbf{I} - \beta_t \mathbf{k}_t \mathbf{k}_t^T) \in [0, 1]$, and $\beta_t = \sigma(\mathbf{W}_\beta \mathbf{x}_t + \mathbf{b}_{\text{dt}}) \in (0, 1)$.

Every fourth layer replaces the linear delta mixer with full Gated Multi-Head Attention with Query-Key RMSNorm and partial Rotary Position Embeddings (RoPE fraction $0.25$). The model incorporates a Multi-Token Prediction (MTP) auxiliary head minimizing joint two-step prediction loss:
\begin{equation}
\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{CE}}(y_t, \hat{y}_t) + \lambda_{\text{MTP}} \mathcal{L}_{\text{CE}}(y_{t+1}, \hat{y}_{t+1}^{(\text{MTP})})
\end{equation}
with $\lambda_{\text{MTP}} = 0.1$.

\subsection{HRM-Text: Dual-Timescale Recurrent Reasoning}
HRM-Text decomposes sequence modeling into two coupled modules: a Low-level module $\mathcal{M}_L$ operating at high frequency and a High-level module $\mathcal{M}_H$ operating at low frequency \cite{wang2026hrm}. For each input sequence $\mathbf{z}^{(0)}$, the dual recurrence executes under an $H_2L_3$ schedule:
\begin{align}
\mathbf{z}_L^{(k+1)} &= \mathcal{M}_L(\mathbf{z}_L^{(k)} + \mathbf{z}_H^{(m)}) \quad \text{for } k=0,1,2 \\
\mathbf{z}_H^{(m+1)} &= \mathcal{M}_H(\mathbf{z}_H^{(m)} + \mathbf{z}_L^{(3)}) \quad \text{for } m=0,1
\end{align}
HRM-Text replaces learnable affine parameters in normalization layers with parameterless Pre-RMSNorm and MagicNorm module-exit normalization:
\begin{equation}
\text{RMSNorm}(\mathbf{x}) = \frac{\mathbf{x}}{\sqrt{\frac{1}{d} \sum_{i=1}^d x_i^2 + \epsilon}}
\end{equation}
Gradient propagation is governed by scheduled Truncated Backpropagation Through Time (TBPTT), linearly ramping the horizon from $k_{\text{bp}} = 2$ to $k_{\text{bp}} = 5$ over the training budget.

\subsection{Mamba: Selective State Space Model}
The Mamba architecture parameterizes a selective continuous-time linear dynamical system:
\begin{align}
\mathbf{h}'(t) &= \mathbf{A} \mathbf{h}(t) + \mathbf{B}(x) x(t) \\
y(t) &= \mathbf{C}(x) \mathbf{h}(t) + \mathbf{D} x(t)
\end{align}
Discretized using zero-order hold (ZOH) with input-dependent timescale $\boldsymbol{\Delta} = \text{softplus}(\text{Linear}(\mathbf{x}_t) + \mathbf{b}_\Delta)$:
\begin{align}
\bar{\mathbf{A}}_t &= \exp(\boldsymbol{\Delta}_t \mathbf{A}) \\
\bar{\mathbf{B}}_t &= (\boldsymbol{\Delta}_t \mathbf{A})^{-1} (\bar{\mathbf{A}}_t - \mathbf{I}) (\boldsymbol{\Delta}_t \mathbf{B}_t) \approx \boldsymbol{\Delta}_t \mathbf{B}_t
\end{align}
The diagonal state matrix $\mathbf{A} \in \mathbb{R}^{d_{\text{inner}} \times d_{\text{state}}}$ is initialized using S4D real structured parameters: $A_{i,n} = -(n+1)$.

\section{Experimental Methodology}
% -----------------------------------------------------------------------------

\subsection{Dataset \& Subword Tokenization}
We utilize the complete Amharic Wikipedia corpus comprising $12,730$ curated articles ($8,906,113$ characters). Tokenization is conducted using a reinforcement-learning-optimized vocabulary of $3,919$ subword units ($V = 3,919$), yielding $6,625,921$ total tokens ($6,294,528$ training tokens, $331,264$ validation tokens) with an average compression ratio of $1.35$ characters per token.

\subsection{Unified Pretraining Configuration}
All models are pretrained using identical optimization hyperparameters:
\begin{itemize}
    \item **Hardware**: $1\times$ NVIDIA A100 80GB PCIe GPU ($bfloat16$ mixed precision).
    \item **Context Length**: $L = 512$ tokens per sequence.
    \item **Optimizer**: AdamW ($\beta_1 = 0.9, \beta_2 = 0.95$, weight decay $0.1$).
    \item **Learning Rate Schedule**: Linear warmup ($50$ steps) followed by Cosine Decay from $\eta_{\text{max}} = 3.0 \times 10^{-4}$ to $\eta_{\text{min}} = 3.0 \times 10^{-5}$.
    \item **Gradient Clipping**: Maximum norm $\|g\|_2 \le 1.0$.
\end{itemize}

\subsection{Key Empirical Findings}

\paragraph{1. Best Generalization Quality: Qwen3.5}
The Qwen3.5 Gated DeltaNet + Multi-Token Prediction architecture achieved the lowest validation cross-entropy loss ($2.2243$) and superior validation perplexity ($\mathbf{9.25}$). The combination of $L_2$-normalized linear associative memory with periodic full multi-head attention provided robust linguistic modeling across long Amharic morphological dependencies.

\paragraph{2. Unprecedented Computational Efficiency: HRM-Text}
HRM-Text demonstrated extraordinary computational characteristics:
\begin{itemize}
    \item **$9.4\times$ Higher Training Throughput**: $43,078\text{ tokens/sec}$ compared to $4,565\text{ tokens/sec}$ for the Transformer.
    \item **$23.8\times$ Lower VRAM Footprint**: Maximum peak memory allocation of only $3.22\text{ GB}$, compared to $76.68\text{ GB}$ for the dense attention baseline.
    \item **Rapid Convergence**: Completed 1 full pretraining epoch over $6.3\text{M}$ tokens in only **$2.5\text{ minutes}$**, achieving competitive validation perplexity ($10.83$).
\end{itemize}

\section{Discussion \& Conclusion}
% -----------------------------------------------------------------------------

Our controlled empirical comparison reveals distinct Pareto-optimal frontiers:
1. **Quality-Optimized Regimes**: For maximum linguistic precision and zero-shot modeling accuracy, hybrid linear-attention architectures with Gated DeltaNet and MTP heads represent the state of the art at the 50M scale.
2. **Resource-Constrained \& Edge Regimes**: For compute-bounded, energy-constrained, or real-time deployment environments, **HRM-Text** provides near-parity linguistic capability while delivering near-order-of-magnitude gains in training throughput and memory efficiency.

All artifacts, tokenizers, checkpoints, and benchmark scripts are released openly for community research.
